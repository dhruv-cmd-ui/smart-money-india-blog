# Pin illustration prompts

Generate one image per prompt (portrait 2:3), save as `docs/pin-art/<slug>.png`, then run `python content-gen/generate_pin_image.py` and commit `docs/pins/` + `docs/pin-art/`.
Without a file in `pin-art/`, the pin falls back to the text-only gradient design.
